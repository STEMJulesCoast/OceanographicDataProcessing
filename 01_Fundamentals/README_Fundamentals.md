# 01_Fundamentals – Data Structures, Plotting, and Functions

This folder contains all materials and notebooks for our **first on-site session** of the *Oceanographic Data Processing Course*.  
We will work through the notebooks together during class. Everything we don’t finish can be completed independently at home.

----
### Overview:
-----
- **`01_DataStructures_and_Plotting.ipynb`**  
  Introduction to fundamental data structures and basic visualization techniques using `xarray`, `numpy`, and `matplotlib`.

- **`02_ClimateDataHandling.ipynb`**  
  Working with climate datasets — reading, slicing, and visualizing NetCDF data in Python.

- **`example_functions.ipynb`**  
  Simple function examples for practicing syntax and logic. Together, we’ll build the `basics` module and explore how to test it.

- **`test_basics.py`**  
  Example of a simple test script using `pytest` to verify function behavior.

- **`03_FunctionsModules.ipynb`**  
  We gradually introduce **Ekman dynamics** and explore how to organize related functions into a module for future use in subsequent sessions.


### Files Created:
- `basics.py`: A module for basic calculating functions like multiplication.
- `ekman_dynamics.py`: A module for calculating Ekman properties.


### Key Learning Outcomes:

- **Automated Data Retrieval:** Learn to access and download data automatically (e.g., via OpenDAP or http).  
- **Data Handling:** Load, merge, and analyze multidimensional datasets efficiently with `xarray`.  
- **Statistical Analysis:** Compute and visualize means, standard deviations, and trends.  
- **Plotting & Visualization:** Create clear, geographic visualizations using `cartopy`.  
- **Functions & Modules:** Build modular, reusable code structures for scientific workflows.  
- **Testing & Debugging:** Use `pytest` to verify correctness and detect logical errors early.
